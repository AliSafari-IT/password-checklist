# Changelog

All notable changes to `@asafarim/password-checklist` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.2] - 2026-09-07

### Changed

- Demo: redesigned homepage, modernized GitHub Pages deployment workflow
- Publish workflow pins README images to the release commit SHA
- Demo: added Buy Me a Coffee widget

## [1.1.1] - 2026-09-07

### Fixed

- Minor fixes and demo improvements

## [1.1.0] - 2026-04-27

### Added

- Extended rule engine, strength labels, and hook API surface
- Dual stylesheet exports (`styles.css`, `default.css`)

## [1.0.0] - 2026-04-27

### Added

- Initial release: `PasswordChecklist` component and `usePasswordValidation`
  headless hook, with built-in rules, custom rules, entropy estimation,
  and common-password checks
